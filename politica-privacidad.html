Política de privacidad de Billar 8 Pro

Última actualización: 25 de noviembre de 2026

Esta política explica cómo Billar 8 Pro puede tratar la información cuando utilizás el juego, incluidas las opciones de inicio de sesión con Google o Facebook, si están habilitadas.

1. Información que puede recopilarse

Según las funciones que utilices, el juego puede recibir información de tu cuenta de inicio de sesión, como nombre público, identificador de usuario del proveedor y correo electrónico (si el proveedor lo comparte y vos autorizás). También puede tratar datos del juego, como perfil, progreso, resultados y preferencias, si esas funciones están implementadas.

La aplicación o sus servicios técnicos pueden generar datos de diagnóstico y funcionamiento, como información del dispositivo, registros de errores y actividad necesaria para mantener el servicio.

2. Inicio de sesión de terceros

Si elegís iniciar sesión mediante Facebook o Google, la autenticación es gestionada por el proveedor correspondiente. Billar 8 Pro solo recibe los datos que el proveedor permite compartir y que autorizás. El uso de esos servicios también está sujeto a sus propias políticas de privacidad.

3. Cómo se utiliza la información

  • Crear o identificar tu perfil dentro del juego.
  • Guardar y sincronizar progreso o resultados, si está disponible.
  • Proteger el funcionamiento del juego, prevenir abuso y solucionar errores.
  • Responder solicitudes de soporte y eliminación de datos.

4. Compartición de información

No vendemos tus datos personales. La información puede procesarse mediante proveedores de servicios necesarios para funciones del juego, autenticación, almacenamiento o mantenimiento. No se comparte con terceros para sus propios fines publicitarios, salvo que esta práctica se informe y exista una base válida.

5. Conservación y seguridad

Conservamos los datos solo durante el tiempo necesario para prestar las funciones del juego y cumplir obligaciones aplicables. Aplicamos medidas razonables para protegerlos; ningún sistema puede garantizar seguridad absoluta.

6. Privacidad de menores

Billar 8 Pro no está diseñado para recopilar conscientemente información personal de niños sin las autorizaciones que correspondan. Si un padre, madre o tutor cree que un menor proporcionó información personal de forma indebida, puede contactarnos para solicitar su revisión y eliminación.

7. Solicitud de eliminación de datos

Podés solicitar la eliminación de tu cuenta y los datos asociados siguiendo las instrucciones de nuestra página de eliminación de datos. Algunos registros podrían conservarse por un período limitado cuando la ley lo exija o para seguridad y prevención de fraude.

8. Cambios en esta política

Podemos actualizar esta política para reflejar cambios en el juego. Publicaremos la versión vigente en esta página e indicaremos la fecha de actualización.

9. Contacto

Para consultas sobre privacidad o tus datos, escribí a: jsaucedoamarilla@gmail.com.
